
# ComputationalNeurosciencePortfolio

My projects and simulations in computational neuroscience.

This repository contains simple neuron simulations in Python:

1. **NeuronSimulation.ipynb** – Single-step neuron activation with sigmoid function.  
   Includes explanations of input vectors, weights, bias, dot product, and neuron firing using sigmoid activation.

2. **single_neuron.py** – Leaky integrate-and-fire neuron simulation over time.  
   Simulates membrane potential dynamics with spikes and plots the result.

Each file includes comments explaining the logic behind the simulation.
